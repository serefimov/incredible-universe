# The Incredible Universe

Игра-головоломка о гравитации, космосе и времени. Игрок меняет начальные условия Вселенной, размещает небесные тела и наблюдает полёт корабля. Корабль начинает с заданными позицией и скоростью; полёт запускается кнопкой Play.

## Текущее состояние

В репозитории сохранён исходный [Spike #0.3](prototypes/spike_0_3.html). В нём работают расстановка тел, навигация по карте, гравитационная симуляция, след корабля и Reset с сохранением расстановки. Уровней, победы и двух времён в этом прототипе пока нет. Историческое название «Властелин Вселенной» внутри HTML оставлено без изменений.

Первый [milestone MVP](https://github.com/serefimov/incredible-universe/milestone/1) — игра для смартфона с обучением и 5–10 вручную спроектированными уровнями. Финальная миссия: вернуться на Землю с допустимой скоростью не раньше чем через 300 земных лет, затратив не более 100 лет собственного времени корабля. Формула двух времён ещё не выбрана.

## Запуск прототипа

Откройте `prototypes/spike_0_3.html` в современном браузере. Установка пакетов и сборка не нужны.

Для проверки со смартфона можно запустить простой сервер из корня репозитория:

```sh
python3 -m http.server 8000
```

На компьютере откройте <http://localhost:8000/prototypes/spike_0_3.html>. На смартфоне в той же локальной сети откройте `http://<адрес-компьютера>:8000/prototypes/spike_0_3.html`. Для этого варианта требуется Python 3.

## Управление

- До запуска: перетаскивайте пустое место для перемещения карты; меняйте масштаб колесом мыши или щипком двумя пальцами.
- Перетащите тело из ящика на карту. В Spike доступно по одному телу каждого типа.
- Нажмите ▶ для запуска. Камера начнёт следить за кораблём; кнопка «Корабль / Слежение» переключает слежение.
- Нажмите ↻, чтобы вернуть время и мир к началу, сохранив расстановку.
- После сброса передвиньте тело или верните его в ящик для удаления, затем повторите запуск.

Прототип используется как точка сравнения. Его ограничения и результаты проверки перечислены в [аудите Spike](docs/SPIKE_AUDIT.md).

## Версии и публикация

Версия продукта хранится в [VERSION](VERSION), изменения — в [CHANGELOG.md](CHANGELOG.md).
Публикация подготовлена для тегов `vX.Y.Z`: каждый выпуск получает каталог
`https://serefimov.github.io/incredible-universe/X.Y.Z/`, корень сайта открывает
последнюю версию. Старые выпуски сохраняются. Первый тег ещё не опубликован.

[Настройка GitHub Pages и порядок выпуска](docs/RELEASES.md). Текущая точка
входа — исторический Spike; новая игра и готовность MVP ещё впереди.
