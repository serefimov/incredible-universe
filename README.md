# The Incredible Universe

Игра-головоломка о гравитации, космосе и времени. Игрок меняет начальные условия Вселенной, размещает небесные тела и наблюдает полёт корабля. Корабль начинает с заданными позицией и скоростью; полёт запускается кнопкой Play.

## Текущее состояние

В репозитории сохранён исходный [Spike #0.3](prototypes/spike_0_3.html). В нём работают расстановка тел, навигация по карте, гравитационная симуляция, след корабля и Reset с сохранением расстановки. Уровней, победы и двух времён в этом прототипе пока нет. Историческое название «Властелин Вселенной» внутри HTML оставлено без изменений.

Новая основа в корневом `index.html` воспроизводит этот цикл с разделёнными
состояниями. В #3 добавлены фиксированный шаг физики и проверка пересечений
с движущимися телами. Повторы и разные расписания кадров сравниваются
на одном шаге симуляции; в #4 редактирование ограничено состоянием
до Play и после Reset, незавершённые жесты отменяются при уходе в фон.
Политика фоновой вкладки и ограничения описаны
в [PHYSICS.md](docs/PHYSICS.md).

Первый [milestone MVP](https://github.com/serefimov/incredible-universe/milestone/1) — игра для смартфона с обучением и 5–10 вручную спроектированными уровнями. Финальная миссия: вернуться на Землю с допустимой скоростью не раньше чем через 500 земных лет, затратив не более 200 лет собственного времени корабля. Контракт двух времён принят в #6: учитывает скорость и гравитационное поле у Земли и корабля. [Формулы и ограничения](docs/TWO_CLOCKS.md); игровые часы внедрены в #7 и показаны над картой.

## Запуск новой основы

Нужен Node.js 20 или новее:

```sh
npm ci
npm run dev
```

Откройте `http://127.0.0.1:8000/`. Чтобы открыть игру на смартфоне в той же
локальной сети, запустите `HOST=0.0.0.0 npm run dev` и откройте
`http://<адрес-компьютера>:8000/`.

```sh
npm run build
npm run check
```

Сборка создаёт один самостоятельный HTML: `dist/game/index.html` со встроенными
стилями и скриптом. `npm run check` проверяет исходный Spike, новую основу,
публикацию и сборку. Исходники используют обычный JavaScript и Canvas 2D;
esbuild нужен только при сборке. [Архитектура и сравнение со Spike](docs/FOUNDATION.md).

Исторический [Spike #0.3](prototypes/spike_0_3.html) сохранён байт в байт
и открывается напрямую в браузере.

`levels/mission-examples.json`, план шести учебных уровней — в `levels/training-plan.json`.
Семь уровней кампании находятся в `levels/campaign.json`: шесть этапов обучения
и «Возвращение на Землю». Кнопка **Уровни** открывает выбор, победа — переход
к следующему заданию. Любой уровень доступен сразу; галочки прохождения
сохраняются в этом браузере. После семи побед появляется завершение кампании.

новичком принята по отчёту владельца от 2026-10-05. Контрольные решения, допуски размещения и финал — [CAMPAIGN.md](docs/CAMPAIGN.md).
Воспроизводимая проверка исторического скрипта:

```sh
node tools/audit-spike.mjs
```

## Версии и публикация

Версия продукта хранится в [VERSION](VERSION), изменения — в [CHANGELOG.md](CHANGELOG.md).
После push в любую рабочую ветку проверенная игра автоматически публикуется
в [dev](https://serefimov.github.io/incredible-universe/dev/). На этой странице
можно выбрать последние сборки веток или конкретный коммит для проверки на
телефоне. Каждая сборка имеет постоянный адрес вида
`dev/0.3.0-alpha.1-012345abcdef/`; сборки сохраняются до следующего стабильного релиза.
При новом релизе предыдущий цикл dev очищается; release сохраняет все выпуски.

Стабильные теги `vX.Y.Z` публикуются в
[release](https://serefimov.github.io/incredible-universe/release/), по адресу
`release/X.Y.Z/`. Старые ссылки `/0.1.0/` и `/0.2.0/` перенаправляют к выпуску.
При разработке VERSION содержит будущую версию с суффиксом. В #9
разработка продолжается с `0.4.0-alpha.1` после подготовки стабильного 0.3.0.
Корень сайта предлагает оба раздела.

[Настройка GitHub Pages и порядок выпуска](docs/RELEASES.md).
Готовность MVP ещё впереди.
