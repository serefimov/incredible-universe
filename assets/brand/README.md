# Оформление The Incredible Universe

Материал предоставлен владельцем проекта 2026-10-07 для #51.

- `source.jpg` — исходная композиция с иконкой слева и эмблемой справа.
- `icon.svg` — квадратная область исходника (24,164), 474×474.
- `emblem.svg` — область с названием (530,0), 750×665.
- `favicon-32.png` — растровая иконка вкладки 32×32.
- `apple-touch-icon.png` — иконка для сохранения страницы 180×180.

SVG содержат исходный JPEG и задают окно просмотра: рисунок не перерисован,
цвета не изменены. PNG экспортированы из `icon.svg` в размерах 32×32 и 180×180.
Исходник также используется для Open Graph превью; абсолютный URL указывает
на материал в основной ветке GitHub и станет доступен после слияния PR.

Титр, favicon и иконка устройства встраиваются в standalone HTML из того же
дерева Git, что и код. Для просмотра игры сеть не нужна. README использует
самостоятельный SVG со встроенным изображением.
